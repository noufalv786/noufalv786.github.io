- `assets/` — project screenshots and visual assets

## Publish with GitHub Pages
1. Create a public repository named exactly `noufalv786.github.io`.
2. Upload all files and folders in this package, preserving the directory structure.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then Save.
5. Visit `https://noufalv786.github.io` after deployment completes.
